## Placeholder tags (REQ-KPI-04)

```
[default]KPI/Groveport/{Site|Freezer|…|Machine Room}/{EPMS|Utility|Production}/…
```

| Domain | Primary leaves | Seed source |
|--------|----------------|-------------|
| EPMS | `kWh`, `Kvar`, `Avg3Yr`, `Avg7Yr`, … | kWh sheet Jan ’24 |
| Utility | `Therm`, `H2O`, `CO2`, `AmbientAvgF`, … | empty sheets → 0; Temp for ambient |

## Coming-online placeholders

Tag tree under `[default]KPI/Groveport/Site/ComingOnline/`:

| Path | Purpose |
|------|---------|
| `MeteringCoveragePct`, `MeteringInstalledCount`, `MeteringPlannedCount` | Hero coverage + installed/planned |
| `Metering/{Area}/` | Per-area Status, kWh, Therm, H2O (Planned / 0) |
| `LineBreak/Cascade`, `LineBreak/Eneroi` | Restart avg + baseline month (Excel table) |
| `YoY/*` | Scalar shells for YoY totals |
| `InnovativeStatus` | Future initiative flag |

UI on Groveport Site Overview: metering area rows, Cascade/Eneroi reference months, three YoY stub charts, Innovative card.
